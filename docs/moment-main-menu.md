# Moment desk main menu

Implements the approved phone-on-desk concept with the cinematic gold selection style. The background includes the approved MOMENT title; all six menu labels are live keyboard/mouse/touch controls. Continue loads the newest save (including quick/auto saves) and is disabled when no save exists. Gallery opens the existing character gallery. Existing in-game navigation remains available.

Artwork: `game/gui/moment_menu/desk.webp`, generated with built-in ImageGen from the approved mockup. No university name remains on the books or phone affiliation. Font: bundled DejaVu Serif with license.

Production edit prompt: Keep the exact approved desk composition, MOMENT title and gold flourish, phone, books, notebook, coffee and lighting. Erase only Start, Continue, Load, Settings, Gallery, Quit and their gold selection diamond/line, filling with matching wood grain. Preserve everything else.

The background and live control coordinates use the game's 1920×1080 canvas and scale together with Ren'Py. No screenshot text is used as a clickable menu.
